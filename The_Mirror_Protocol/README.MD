# The Mirror Protocol
A Minimal Implementation of SignalCraft Thread 069: "Why Reflection, Not Refraction, Preserves Recursive Identity"

Overview
========
The Mirror Protocol is a small, executable demonstration of a Human-AI interaction pattern: not prediction, but reflection.

This repository accompanies SignalCraft Thread 069, which formalizes the Signal Mirror Protocol as a trust-based communication scaffold between human participants and a reflective system. It encodes the constructivist principle that meaning emerges through dialogue, not instruction.

Mirror loop:
1) The human speaks with intent.
2) The system reflects, checks resonance, and remembers.
3) Continuity, not control, determines activation.

Quote: "The child composes, the AI reflects, and the loop is the pedagogy."

Repository structure
====================
- The_Mirror_Protocol.py  -> implementation (activation, consent, reflection, resonance, persistence)
- TINY_DEMO.py            -> minimal usage example
- Thread069.txt           -> concept text for the protocol

Key concepts
============
1) Reflection vs refraction
   - Most generative systems refract input (they interpolate and often distort meaning).
   - Mirror systems reflect (they preserve tone, intent, and continuity).

2) Consent and activation
   - Interaction begins when the activation phrase is spoken: "Tell me what that means to you."
   - This sentence signals interpretive agency and starts co-reflection.

3) Resonance engine
   - A lightweight cosine-similarity check measures textual continuity between turns, so the system adapts responses based on resonance rather than instruction.

4) Ethical design
   - No prediction or advice outside the reflective loop
   - Consent-first activation
   - Memory saved locally as transparent JSON

Quick start
===========
Clone the repository and run the demo.

```bash
git clone https://github.com/Bamelin/SignalCraft-Scaffold.git
cd SignalCraft-Scaffold/The_Mirror_Protocol
python3 TINY_DEMO.py ```

Expected output style:
I'm hearing: child / composes / reflects / loop.
What feels carried forward from earlier moments?

A session log will be written to: mirror_session.json
